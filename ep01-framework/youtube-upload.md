Most candidates lose a system design interview in the first 5 minutes by drawing before they ask. This video gives you one framework you can use on any system design question, and we use it to design a URL shortener from scratch.

The 5 steps:
1. Clarify: users, scale, and the "never-happen" rule
2. Interactions: write the APIs
3. Data: entities, the main read, the riskiest write
4. Simple design: the smallest thing that works, then trace a request
5. Challenge: break it, fix it, name the cost
